# Original illustrated motion extraction

Run `python -B tools/media/survival_animation/build.py` from the repository, then `python -B tools/media/survival_animation/validate.py`. Requires Python3.11+, Pillow, numpy and scipy. The builder owns only the new `assets/art/survival/motion` tree; it never calls historical packers or changes shared art/Java/registries.

The built-in image_gen produced original painted poses. Retained full source sheets, exact prompts, output identities, selections/rejections and one blocked request are in `source/GENERATION.json`; every retained source/prompt has a SHA256 in `source/HASHES.json`. Extraction isolates connected sprites and their antialias fringes, uniformly scales each master once, normalizes transparent canvases and packs metadata. It does not paint, mirror, warp, hinge, interpolate or synthesize motion from a static pose.

`clips.json` version1 has thirteen clips / eighty-seven frame bindings / eighty-four distinct PNGs. Four officer walking clips each contain twelve drawings at24fps; three machine walking clips contain eight at16fps. Each .5-second loop is intended to cover two .25-second cells. East/south/west pistol fire has four frames at70ms, release atframe2 and recovery atframe3; static aim aliases the authored aim drawing. North pistol action was rejected by the image service and is absent. Only the pistol equipment is depicted. Machine drawings preserve their original three-quarter view; they do not establish cardinal facing art.

Frame coordinates use a256px reference cell. Respect each frame's width/height and bottom-left normalized pivot; padded canvases are taller than the1.3-cell officer reference silhouette. A common clip pivot is calibrated once to the solid painted sole and stays identical across all frames. Do not independently scale each silhouette to1.3cells or center a changing bounding box in runtime. Carry walking phase across consecutive cells; restarting atphase0 on every .25-second cell discards half the cycle. Play gait only for authorized movement, never during tactical waiting. Freeze the animation clock on pause/focus loss. A renderer must not add sine bob or duplicate generic recoil.

`editable-motion.ora` exposes each exported pose as its own editable layer; original flattened masters remain available. This does not claim brushstroke layers or a painted animation project. `review/playback.html` is a pause/step browser preview; serve the repository's assets directory, for example with `python -m http.server 8871 --bind 127.0.0.1 --directory assets`, then visit `/art/survival/motion/review/playback.html`. The animated WebP/GIF files and contact sheets offer offline review. GIF time quantization preserves a500ms cycle. Browser screenshots are actual technical-preview captures, not gameplay evidence.

Validation checks source hashes, authored frame uniqueness, consistent scaling/canvas/pivot, at most one reference-pixel solid-sole anchor drift, bounded paths/crops, true alpha, real multi-frame preview duration, editable archive CRC and a full byte-identical rebuild. It cannot verify planted feet during runtime translation, proper anatomical gait, normal-speed release/audio synchronization, artistic success or commercial quality. Front/rear phase choreography remains an explicit quality concern; rejected mixed-master tests are retained in `review/rejected-splice-*`. Do not promote a twelve-frame count into artistic acceptance.
