# Bounded production and listening gate

Status: proposed work, not executed. Owner intent: unsettled, tense, attentive. Baseline `18938ec` stays available as the control. This task changes documents only.

## Produce one small comparison first

Do not replace the full soundtrack on the strength of source inspection. Make one 90-second exploration treatment with station/suit detail and musical gaps, plus one 30-second hypoxia/recovery treatment using the same palette. Supply a short real R.O.V.E.R. arming/turn-change cue set separately. Keep editable synthesis/arrangement source and per-layer exports; document provenance. Retain existing IDs/control exports until the lead authorizes integration.

The comparison should answer three decisions: whether reduced musical certainty better serves the owner; whether the body is present without becoming a metronome; whether real threat cues remain recognizable. A new middleware, new gameplay hearing system, voice acting, all-sector replacement, or complete recomposition is outside this first pass.

## Listening procedure

Use the same isolated seed/save and actions for control and candidate. First match the normal exploration portions by listening and level measurement so extra volume does not win the comparison. Keep master/device level fixed during each pair; note any adjustment. Try the presentation on ordinary headphones and stereo speakers, then mono at a modest volume. The owner should hear the actual current Windows game; a standalone render is only preliminary asset feedback.

| Scenario | Required actual check |
| --- | --- |
| Healthy exploration / deliberate pause | Listen for 90 seconds including 20 seconds of thought without actions. Can small machine/body details hold attention? No warning should escalate merely because real time passed. |
| Real threat in view | Recognize S.I.R.S./A.D.D./R.O.V.E.R. without reading their names. Hear the relevant action above music; note repeated cue fatigue. No concealed actor should become a precise music/position radar. |
| Armed R.O.V.E.R. / open menu | Commit one fuse step, wait/read, then return. Sound must not claim detonation occurred or an ETA elapsed while world ticks stayed fixed. The useful arming identity must remain different from a phantom. |
| Oxygen 100→warning→critical→refill→recovery | Verify the actual state trace alongside listening. Does each escalation convey strain without covering the refill success? Body/impressions ease with real oxygenation; no leftover urgent loop after recovery. |
| A.L.I.C.E./Carmack and final choice | Read slowly, page text and wait. Music leaves room for words and emotional uncertainty; it does not nag the listener to advance or score the sacrifice as a loot reward. |
| Loops and boundaries | Hear at least two full wraps of each revised cue; test combat/danger/ending boundaries first. Test healthy↔danger↔combat, dialogue, death, ending, pause/focus/resume. No click, abrupt restart, duplicate loop or unresolved loudness jump. |
| Crowded mix / settings | Combine real fire, impact, ROVER, warning and refill. Check mono and low volume, master/music/SFX sliders, mute and focus. Important cues must survive without requiring the listener to turn everything up. |

Each listener records before discussion: tension 1–5, annoyance 1–5, urge to lower volume yes/no, what they believed was happening, and a timestamp for the strongest and weakest moment. These ratings are a comparison aid, not a population study. Use the owner's artistic judgment to choose the direction; record disagreement rather than averaging it away.

## Acceptance and handoff

Accept a slice when the owner can describe the intended unease, wants to keep listening at a comfortable fixed level, identifies the important true cues, and experiences relief after recovery. Fail/revise if the treatment mainly produces impatience, conceals useful information, creates a fake real-time deadline, or makes quiet passage feel like an audio fault. Silence is intentional only if the surrounding details and transition make it feel intentional.

For every candidate report separately: authored/exported, decoded/level checked, integrated, current Windows playback, actually heard, owner accepted. Successful backend calls and a loop counter do not prove listening. Retain exact source/build ID, asset hashes, scenario action trace, output device/settings and short written notes. Keep original control, first failures and isolated saves. No live owner save is needed.

Only after this slice is heard and selected should the lead extend the palette across all six roles and 28 effects, refresh sound provenance/registries, and rerun the relevant packaging/audio/turn-determinism checks. Source implementation may never advance turns, alter collision, consume oxygen, or draw from combat/loot RNG to create atmosphere.
