# Preserved pre-survival test contracts

These unchanged tests belong to release0.1 at e6f2ec2 and remain recoverable here and in Git. Their XP/stat allocations, living NPC/physical ALICE,24-category inventory,900-unit start, mandatory prose and old save/schema/replay assumptions were explicitly superseded by the owner-approved21October2026 survival design. They are not tests of release0.2 and are excluded with the existing legacy tree. Run them from the preserved release checkout.

Active survival tests replace those contracts with conservation, senses/machine memory, physical narrative, generated budget/route and persistence/recovery scenarios. The independent pure perception and state-boundary tests were retained in active tests. Existing audio, presentation and settings tests remain active unless an individually documented new contract requires replacement. Do not call historical replay success verification of the redesigned campaign.

HelmetAudioTest is also preserved unchanged: its nine-dialogue trust-dependent campaign voice mapping belongs to the removed RPG dialogue system. Active survival speech binds28 exact authored lines through audio/survival/exchanges.json and native completion-history checks; old AudioDirector helper tests are retained only as historical helper regressions, not survival speech acceptance.
